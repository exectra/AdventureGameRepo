Known Issues and Limitations:
- Breaking multiple destructible box can cause the sound to clip 

How to run the game:
Follow the in-game controls and play the game as intended.
- WASD: Movement
- Mouse: Move Camera
- Left Click: Attack/ Button Press
- Spacebar: Jump
